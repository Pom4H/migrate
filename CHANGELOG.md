# Changelog

All notable changes to this project will be documented in this file.

## 0.1.0 — 2026-09-03

- Added the TypeScript migration DSL.
- Added sitemap and same-origin link discovery.
- Added immutable raw snapshots and deterministic normalized outputs.
- Added durable TypeScript or JSON overrides.
- Added entity-level semantic diffs.
- Added route, identity, asset, removal, override, and fingerprint checks.
- Added CLI commands for init, pull, sync, diff, check, and CI generation.
- Added Bun 1.4 and TypeScript 7 build, test, and publishing workflows.
